## Agent Tasks

### Adding a Workflow
1. Create folder: `workflows/N-workflow-name/`
2. Save JSON as `workflow.json`
3. Create `README.md` using template above
4. Create `screenshots/` folder
5. Update `PORTFOLIO.md` with new entry
6. Update landing page cards if featured

### Naming Convention
- Folders: `N-lowercase-hyphenated-name`
- Number prefix for ordering priority

### Key Rules
- **Quantify everything**: Time saved, accuracy %, setup time
- **No credentials**: Use `YOUR_API_KEY` placeholders
- **HR-first language**: Problem → Solution → Impact
- **Visual proof**: Include workflow screenshots
